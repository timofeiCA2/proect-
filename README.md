# Утилита для массового пинга хостов

## Описание
Простая утилита на Python для одновременной проверки доступности множества хостов. 
Позволяет быстро определить, какие серверы/сайты доступны, а какие нет, 
собирает статистику времени отклика и экспортирует результаты.

## Возможности
- Массовая проверка доступности хостов (доменов или IP-адресов)
- Интерактивный режим ввода хостов
- Чтение списка хостов из файла
- Статистика: среднее/минимальное/максимальное время отклика
- Расчет процента потери пакетов
- Экспорт результатов в JSON и CSV форматы
- Ограничение количества одновременных подключений
